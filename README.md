# Inquiniso - Project Suite

## 🎯 Project Trinetra: Karmic Quest Manager
**Live Link**: https://lunaticinquiniso-bot.github.io/inquiniso/trinetra/

A mystical quest management system with karma tracking, prana economy, and cosmic deadlines.

- **PIN**: Not required (auto-unlock after intro)
- **Features**: Quest creation, task tracking, reward system, archive
- **Storage**: Browser localStorage (persists between sessions)

---

## 📖 Project Crescent: Akashic Diary
**Live Link**: https://lunaticinquiniso-bot.github.io/inquiniso/crescent/

A PIN-locked personal diary with daily entries and moonlit aesthetics.

- **PIN**: `2027`
- **Features**: Daily journal, calendar chronology, sealed records archive
- **Storage**: Browser localStorage (persists between sessions)

---

## 🚀 How to Use

1. Click either link above
2. Click to awaken the project
3. Wait for the cinematic intro (~15 seconds)
4. For Crescent: Enter PIN `2027`
5. Start using the application

Both applications use **browser localStorage** to persist your data across sessions. Your entries and progress are saved locally on your device.

---

## 📝 Notes

- **Audio**: YouTube background music plays automatically
- **Browser Support**: Works on all modern browsers (Chrome, Firefox, Safari, Edge)
- **Mobile**: Responsive design works on tablets and phones
- **Data**: All data stored locally (no server sync)
